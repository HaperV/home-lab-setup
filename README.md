# Домашняя лаборатория

Это мой первый проект на GitHub. Здесь я буду описывать процесс настройки виртуальной машины с Ubuntu Server.

**Автор:** Никита Белоусов  
**Дата создания:** 10 ноября 2026

**Что сделано:**
1. Настроен межсетевой экран UFW (резрешены порты SSH и HTTP);
2. Проверено удаленное подключение к серверу по протоколу SSH из ОС Windows;
3. Проверен аудит открытых портов сервыера с помощью утилиты **Nmap** (`nmap -sV`);
4. Подтверждена корректная работа правил межсетевого экрана (UFW): доступны только порты 22 (SSH) и 80 (HTTP);
5. Проведен внешний аудит безопасности сервера из ОС Windows с помощью команды **PowerShell** (`Test-NertConnection`);
6. Настроена статическая IP-адресация через Netplan для обеспечения стабильности сетевых сервисов
